# Scripts

`setup_ryu_stage2.sh` reconstructs or checks the isolated Python 3.11 Ryu runtime used by Stage 2. It pins an upstream source commit and leaves the main project environment untouched. See [Ryu runtime setup](../docs/architecture/ryu-runtime-setup.md).

There are no Stage 3 traffic generation scripts. The Stage 3 scenario document is a plan only; any future scenario implementation must stay within its reviewed local Mininet bounds and cleanup requirements.
