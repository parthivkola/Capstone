# Experiment Matrix

This matrix is an implementation-oriented planning artifact derived from [research-protocol.md](research-protocol.md). It contains no experimental results. “Acceptance” means the conditions for retaining an experiment as valid evidence; it is not a claim that the hypothesis will be supported.
